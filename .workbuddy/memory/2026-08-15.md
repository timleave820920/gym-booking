- **根因（两层）**：①`wx.chooseAvatar` 是纯 JS API **仅真机生效**，开发者工具模拟器不支持（工具里无响应是正常的）②`app.json` 缺 `requiredPrivateInfos: ["chooseAvatar","nickName"]` → 真机授权链路被静默拒绝（不弹窗、无报错）
- **修复**：app.json 补 requiredPrivateInfos 声明（342f836）
- **已推送 GitHub（98487a3）**——包含之前积累的昵称点击修复/头像API改造/提示条逻辑，网络恢复后全部上线
- **验证注意**：真机扫码测头像（工具模拟器不支持 chooseAvatar API）；另外微信后台需在《用户隐私保护指引》声明「选中的照片或视频信息」用途（真机隐私弹窗要求）

## 昵称失焦自动保存（22:19）

- 需求：用户一键填入微信昵称后自动保存，无需再点保存
- 实现：input 加 bindblur="autoSaveNick"——微信 nickname 键盘「一键填入」后自动收起键盘触发 blur → 自动保存；saveNick 加 silent 参数（失焦触发时空值不弹错）；手动输入仍可点保存按钮
- git 提交 3e593f0 + 推送 80604e8
