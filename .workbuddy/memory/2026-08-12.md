## 修复：app.wxss 编译错误（WXSS unexpected char）

**现象**: 编译报 ./app.wxss(7:85) unexpected 字符。

**根因**: 主题改造批量注入 --vip-bg 时用 replace 匹配 `/* 页面底` 截断了原注释，导致 `（V2 质感：白→极浅青微渐变由页面自行叠加） */` 残留在新行末尾且位于注释外——`→`（U+2192, Sm 类别）在 WXSS 注释外触发 unexpected。

**修复**: 恢复原注释并合并正确两行（--bg 注释闭合 + --vip-bg 独立注释）；全文件扫描确认无非安全字符。提交 6f7b1xx。

**经验**: 批量字符串注入 CSS 时若匹配串短于完整注释，务必检查注释闭合与残留文本；微信 WXSS 对注释外的箭头/emoji 类字符（Sm/So 类别）会报 unexpected。
