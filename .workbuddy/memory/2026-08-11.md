## 第八轮：登录 400 Bad Request 修复（重要 Bug）

**现象**: 真机/模拟器 POST /api/auth/login 返回 400 "缺少 openid 或 code"。

**根因**: code2Session() 在**未配置 WX_SECRET 环境变量**时 `resolve({})`（空对象）；handleLogin 只处理 `session.openid`（真 openid）和 `session.errcode`（换取失败）两种分支——**空对象两头都不占 → finalOpenid 保持 null → 400**，客户端传的 openid 被丢弃。之前测试通过是因为当时带 WX_SECRET（假 code 返回 errcode 走降级分支）；本次服务重启未带 secret 即踩中。

**修复**（server/index.js handleLogin，已推送 c0e4eea）: code 分支改为——有 openid 用真 openid；否则**一律回退客户端 openid**（errcode 时仅告警日志）。

**验证**: 带 code+openid → 201 注册成功（wechatVerified:false）；只带 code → 仍 400（合理）。

**经验**: 双分支（openid/errcode）遗漏"空返回"路径是经典漏洞；服务重启不带环境变量会改变行为——`一键启动.bat` 启动后应检查 WX_SECRET 是否传入。
